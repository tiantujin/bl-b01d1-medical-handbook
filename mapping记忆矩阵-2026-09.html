DAR＝药物抗体比。载荷家族决定毒性谱（详见矩阵 F），靶点决定脱靶方向与人群筛选逻辑。"双靶 ADC"目前进入 III 期并取得阳性的只有 EGFR×HER3（BL-B01D1）。

从矩阵 B 可推出的三条规律
  1. 载荷是稀缺资源：乳腺癌 ADC 里 TOP1i 占绝大多数（DXd / SN-38 / Ed-04 / KL610023 全属此类）→ 交叉耐药是领域共同问题。
  2. 靶点决定"谁能用"：HER2 轴需表达（low/ultralow 起）、TROP2 不需表达但正常组织也表达（黏膜/眼毒性）、HER3 需检测、EGFR×HER3 目前不需筛选。
  3. 连接子决定"毒性形状"：稳定连接子（Dato-DXd）→ 游离载荷低、血液学轻；pH 敏感（SG）→ 全身暴露高、血液学+腹泻；不可裂解（T-DM1）→ 血小板↓特征。
一句话记住每款药
  • T-DXd：HER2 轴全域之王（1L→新辅助都有）｜警戒 ILD
  • T-DM1：non-pCR 辅助金标准，被 T-DXd 后移｜血小板↓
  • SG：TROP2 老将，走向 1L 免疫联合｜腹泻+中性粒
  • Dato-DXd：更前线的 TROP2（未化疗人群）｜口腔炎+干眼
  • SKB264：中国可及性最强（医保）｜口腔炎+血液学
  • BL-B01D1：唯一双靶、覆盖 IHC 0 全谱｜血液学为主、ILD 1.4%
  • HER3-DXd：HR+ 潜在竞争者，III 期进行中｜ILD 4%

矩阵 F 的"结构—毒性"记忆链
  • 载荷家族决定谱系：TOP1i（DXd/SN-38/Ed-04/KL610023）→ 血液学 + 消化道 ± ILD；微管（MMAE/DM1/DM4）→ 神经 + 血小板 + 眼表。
  • 连接子稳定性决定血液学轻重：稳定（Dato-DXd，游离 DXd <1 ng/ml）→ 血液学轻；pH 敏感（SG）→ 血液学 + 腹泻重。
  • 靶点在正常组织的表达决定脱靶方向：TROP2（口腔/角膜/唾液腺）→ 口腔炎 + 干眼；EGFR（皮肤）→ 皮疹；HER2 相对安全 → 但 DXd 系 ILD 仍是主要关切。
  • ILD 风险梯度（观察性）：DXd 系（T-DXd / Dato-DXd / HER3-DXd）报告需重点管理 > Ed-04/SN-38 报告率低 > 微管类低。
iza-bren 安全性的"三句话记忆版"
  1. 血象是主战场：Ⅲ 期 ≥3 级中性粒↓ 58%、白细胞↓ 56%、血小板↓ 52.7%、贫血 46.9%，任何级贫血 97%，FN 5.3%。
  2. 但恢复快、不停药：3–4 级中性粒中位恢复 4 天，减量/中断各 63%（常规操作），因 AE 停药仅 1.9%。
  3. ILD 不是主要信号：III 期 1.4% 且无 ≥3 级（独立裁定后约 0.5%）；乳腺癌 I 期、SCLC Ib、全球 I 期均 0 例。

助记口诀区背下来这些句子，就等于背下了两个 mapping

① 乳腺癌格局：五句话覆盖全部矩阵 A

  1. HER2+ —— ADC 全域前移：新辅助（T-DXd 序贯 THP，中国 2026-03 获批）→ 辅助（non-pCR：T-DM1 → T-DXd）→ 1L（T-DXd + 帕妥珠）→ 2L（T-DXd）→ 后线（国产换代）。
  2. HR+ —— 窗口在化疗之前：1L 仍是"内分泌 + CDK4/6i"；进展后、化疗前是 ADC 窗口（HER2-low → T-DXd；IHC 0 → TROP2 ADC）。
  3. TNBC —— 一线化 + 分人群：1L 由"化疗 + 免疫"扩成"Dato-DXd（免疫不适用）/ SG + 帕博利珠（CPS≥10）/ SKB264"；2L 是 SG / SKB264 / BL-B01D1。
  4. HER2-low —— 按表达分流：low/ultralow 走 T-DXd；检测有异质性，复发建议再活检。
  5. IHC 0 —— T-DXd 的盲区：只能靠 TROP2 ADC 或双靶 ADC（BL-B01D1，HR 0.28）。

② ADC 记忆：两个坐标定位一款药

口诀："先看靶点（HER2 / TROP2 / HER3 / EGFR / 双靶），再看载荷（DXd / SN-38 / Ed-04 / KL610023 / 微管）。"
· 三个 TOP1i 老面孔：DXd（T-DXd、Dato-DXd、HER3-DXd）、SN-38（SG）、KL610023（SKB264）；
· 一个新载荷：Ed-04（BL-B01D1）；
· 微管系：T-DM1（DM1，血小板）、MRG003 / RC48（MMAE，神经 + 皮疹）；
· 双靶：EGFR×HER3（BL-B01D1，唯一 III 期阳性）、TROP2×HER3（JSKN016）、TROP2×B7H3（IBI3017）。

三条"数字纪律"（比记住数字更重要）：① 说数字必带人群与线数（"在 TNBC 1–2 线后人群，mPFS 8.5 个月"）；② 两套数据不混用（I 期 121 例 ≠ III 期 418 例，6.9 ≠ 8.5）；③ n 太小的数字不引用（n=3 的 cORR 100%、n=23 的 39.1% 只能说"早期单臂观察"）。

④ 一页串讲：把两个 mapping 用 60 秒讲完

"乳腺癌 ADC 现在是三轴三分、时间轴前移：HER2 轴（T-DXd 全域、已到新辅助）、TROP2 轴（SG / Dato-DXd / SKB264 从后线走向一线和化疗前）、以及双靶新轴（BL-B01D1 的 EGFR×HER3，覆盖 HER2 IHC 0 全谱）。决策变量从"有没有 ADC 用"变成"按 HER2 表达分流、按线数排位、按毒性谱选人"。

BL-B01D1 自己的位置是：三项 III 期阳性（鼻咽癌、食管鳞癌、TNBC），两项已获批、TNBC 在审；TNBC 1–2 线后的 III 期数据是 mPFS 8.5 vs 3.1、mOS 15.9 vs 12.5、cORR 51.7%，IHC 0 亚组 HR 0.28、HER2-low 亚组 HR 0.32，说明疗效不依赖 HER2 表达——这正是它能覆盖 T-DXd 够不到的那部分患者的依据；安全性以血液学为主但恢复快、停药率仅 1.9%，ILD 1.4% 且无 ≥3 级。

现在还缺的三块是：早期乳腺癌（新辅助/辅助）无数据、既往 ADC 经治人群无 III 期数据、与同类 ADC 无头对头——这三条也是面对专家质疑时必须主动说清楚的边界。"
