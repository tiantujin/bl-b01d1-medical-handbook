2.2 机制要点（差异化叙事核心）

  1. 双靶协同，破解异质性与耐药：EGFR 与 HER3 在多种实体瘤广泛共表达，可形成异源二聚体驱动肿瘤增殖存活。双靶同时阻断，降低单靶治疗常见的"靶点异质性/动态表达变化"导致的获得性耐药风险；HER3 在靶向治疗压力下会上调并介导旁路激活，双抗ADC可同时压制。
  2. 更强内吞、更精准杀伤：双抗结合促进肿瘤细胞内吞效率，配合高 DAR（≈8）与可裂解连接子，实现高效载荷递送。
  3. 更低正常组织毒性（关键安全叙事）：双抗设计降低了对正常表皮细胞 EGFR 的单价结合强度，因此严重皮疹、腹泻的发生率显著低于传统 EGFR 单抗或单靶 EGFR ADC；主要毒性为可管理的血液学毒性。

第3章 疾病领域：实体瘤与乳腺癌

3.1 乳腺癌流行病学与分子分型

  • 流行病学：乳腺癌是全球女性发病率最高的恶性肿瘤之一；中国每年新发约35-40万例，发病率居女性恶性肿瘤首位，且年轻化趋势明显。
  • 分子分型（临床四大类）： 1. Luminal A/B（HR+/HER2-）：占比约65-70%，内分泌治疗为基础； 2. HER2阳性：约15-20%，抗HER2靶向（曲妥珠单抗/帕妥珠单抗/T-DXd等）； 3. 三阴性乳腺癌（TNBC）：ER/PR/HER2均阴性，约10-15%； 4. HER2低表达（HER2-low，IHC 1+或2+/ISH-）：作为治疗分层的新维度，约占HER2阴性乳腺癌的50%+，T-DXd等HER2 ADC适用。
  • 重要概念：HER2 IHC 0 ≠ HER2低表达；传统上HER2阴性包含"低表达+IHC 0"，两者对HER2 ADC的适用性不同——BL-B01D1的获益不依赖HER2表达水平。

3.2 TNBC深度专题（BL-B01D1主战场，重点掌握）

  • 特征：占乳腺癌10-15%，却占乳腺癌相关死亡的约25%；发病年龄较轻、侵袭性强、早期易转移、复发率高；晚期5年生存率仅约12%，是所有亚型中最差。
  • 治疗现状：
  • 1L：以化疗为基石（紫杉类、吉西他滨等）；PD-L1表达阳性（约<20%）可联合免疫（如帕博利珠单抗+化疗）；胚系BRCA突变者可用PARP抑制剂。
  • ≥2L：传统单药化疗mPFS仅2-5个月、mOS难以突破1年；TROP2 ADC（SG/SKB-264）获批于≥3L（部分2L）；抗HER2 ADC仅覆盖HER2低表达人群。≥2L全人群（尤其HER2 IHC 0）长期缺乏III期高级别证据——这就是PANKU-Breast 02填补的空白。
  • 临床决策关键分层变量：治疗线数、PD-L1状态、HER2表达水平（IHC 0 vs 低表达）、胚系BRCA、内脏转移（肝/肺）、ECOG PS、既往免疫治疗史。
  • BL-B01D1 的临床定位叙事："≥2L TNBC 全人群均可获益（无论HER2表达），且生存获益（PFS 8.5个月 / OS 15.9个月）+ 生活质量（低ILD、低体感AE）双优"。

3.3 HR+/HER2- 晚期乳腺癌（管线延伸战场）

  • 治疗路径：内分泌治疗±CDK4/6抑制剂为一线主流；进展后按内分泌敏感/耐药分层，可选化疗、ADC（T-DXd用于HER2低表达内分泌经治人群）、PI3K/AKT抑制剂（PIK3CA突变）等。
  • BL-B01D1相关性：全球IZABRIGHT-Breast01研究纳入"不适合内分泌治疗的一线ER低表达BC（ER低表达约占10%）"人群，是乳腺癌领域向前线延伸的布局。

3.4 非小细胞肺癌（NSCLC）速览

  • 分层：驱动基因阳性（EGFR/ALK/ROS1等，EGFR突变中国占比高）→ TKI治疗；驱动基因阴性 → 免疫±化疗（PD-L1分层）。
  • BL-B01D1相关性：EGFR-TKI耐药后NSCLC全球III期（FDA突破性疗法）；2026-05获批联合小分子靶向用于驱动基因阳性NSCLC的临床研究。EGFR高表达NSCLC是ADC合理靶点人群。

3.5 其他实体瘤管线（鼻咽癌、食管鳞癌、尿路上皮癌、卵巢癌）

  • 鼻咽癌：中国高发（华南尤甚）；EBV相关；后线治疗有限。BL-B01D1为首个获批的NPC后线ADC适应症。
  • 食管鳞癌：中国新发22.4万/年（占全球43.8%），存量74.2万；ESCC占中国食管癌90%+；5年生存率<6%；免疫联合化疗进展后2L无标准方案——BL-B01D1为全球首个ESCC获批ADC。
  • 尿路上皮癌/卵巢癌/胆管癌：注册研究推进中，了解布局即可。

3.6 临床终点与统计学速成（医学经理必备语言）

  • ORR（客观缓解率）：CR+PR患者比例；cORR=确认的ORR。
  • DoR（缓解持续时间）：从首次缓解到进展/死亡的时间。
  • PFS（无进展生存期）：随机化到疾病进展或死亡；是ADC类注册研究主要终点，反映疾病控制速度与深度。
  • OS（总生存期）：金标准终点，受后续治疗影响。
  • HR（风险比）：两组事件风险之比，HR<1 表示治疗组优于对照组（如0.29=风险降71%）；解读时注意置信区间（CI）与P值。
  • mPFS/mOS：中位值，代表50%患者达到的时间点；"中位"不等于"平均"，且曲线尾部获益可能更显著（需看生存曲线形态）。
  • 亚组分析：预设亚组结果用于支持全人群结论的稳健性；未预设的亚组比较仅作探索。
  • BICR vs 研究者评估：盲态独立中心审查（BICR）可降低评估偏倚，注册研究通常以BICR为主要终点依据。

第5章 医学策略与证据生成

5.1 医学计划（Medical Plan）方法论

医学计划是医学部年度工作的纲领，通常包含：

  1. 治疗领域与产品现状分析：适应症、指南地位、竞品证据、处方行为、未满足需求；
  2. 医学洞察（Medical Insights）：通过KOL访谈、MI趋势、市场反馈提炼关键医学问题；
  3. 医学目标（Medical Objectives）：如"建立BL-B01D1在≥2L TNBC的BIC证据地位""推动指南纳入"；
  4. 证据生成计划（Gap→Study）：从证据缺口推导研究类型与优先级；
  5. 外部沟通计划：KOL互动、会议、医学教育；
  6. 资源与预算、KPI与评估。

5.2 证据缺口分析与证据生成阶梯

证据缺口常见来源：① 注册研究之外的人群（真实世界更宽的人群）；② 中国人群数据；③ 联合治疗/序贯治疗数据；④ 长期安全性；⑤ 经济学与生活质量数据；⑥ 指南纳入所需的比较数据。

证据生成阶梯（从低到高投入）：文献/荟萃分析 → 登记研究/观察性研究（RWS）→ 干预性研究者发起研究（IIR/IIT）→ 公司赞助的上市后确证研究（PMR/PMC）→ 新适应症注册研究。

BL-B01D1 落地示例（假设性方向，需与公司策略对齐）： - 短期：TNBC ≥2L真实世界使用研究（疗效/安全性验证）、HER2 IHC 0 人群专向观察； - 中期：与T-DXd/SG的比较研究、联合免疫探索、HR+/HER2-（ER低表达）探索； - 长期：1L布局（IZABRIGHT-Breast01相关中国人群数据支持）、生物标志物研究（EGFR/HER3表达、Ed-04敏感性）。

5.3 上市后研究类型与管理要点

类型 定义 医学经理角色 关键控制点
IIR/IIT（研究者发起的研究） 研究者发起并主导，公司提供资金/药物支持 审批、监督、跟进、结果沟通 科学性、合规、知识产权与数据归属、利益冲突

5.4 IIR/IIT 全流程管理（高频业务，务必掌握）

标准流程（六步）： 1. 申请受理：研究者提交研究方案/摘要（含科学依据、设计、终点、统计、预算）； 2. 科学评审：医学评审（科学价值、可行性、样本量、终点合理性、伦理风险）+ 必要时统计评审； 3. 合规审查：利益冲突声明、资金合理性、合同条款（数据归属、发表权）； 4. 合同与执行：签署协议、首付款、项目启动（伦理批件、人类遗传资源审批等）； 5. 过程监督：入组进展、中期报告、安全性事件上报、偏差管理； 6. 结题与发表：结题报告、数据所有权确认、成果发表支持（研究者署名规则）、成果归档。

常见风险与对策：研究者要求超范围资金（按政策拒绝并记录）；数据归属争议（合同前置明确）；入组缓慢（提供中心筛选建议、必要时沟通调整）；安全性事件（立即上报PV，按法规时限）。

  • 定义暴露（BL-B01D1用药方案）与结局（疗效、安全性、生活质量）；
  • 处理混杂（倾向性评分、多因素校正）、缺失数据与随访偏倚；
  • 样本量与统计假设前置；
  • 伦理审查与知情同意（回顾性研究豁免条件按机构规定）。

5.6 研究成果发布与沟通

  • 医学部主导/参与的成果发布：学术会议摘要/口头报告、SCI期刊发表、公司新闻稿（需医学审核）；

第7章 医学信息服务（MI）

7.1 MI 工作流程（标准闭环）

  1. 接收与分类：来源（医生/药师/患者/销售/内部）、渠道（电话/邮件/微信/会议现场）、紧急度；
  2. 评估：是否涉密/涉法（如超适应症、投诉、疑似ADR）、是否需要升级；
  3. 检索与应答：基于经批准的医学问答库与文献证据，撰写应答；
  4. 审核与发送：医学审核→合规检查→发送并记录；
  5. 归档与趋势分析：记录查询类型、频率，输出MI洞察（如医生高频关注"HER2 IHC 0能否获益"→提示培训与内容需求）。

7.2 医学问答库建设

  • 按主题组织：产品机制、获批适应症用法用量、疗效数据、安全性/不良反应处理、特殊人群、输注操作、临床研究进展、超适应症问题标准应答；
  • 每条QA含：问题、标准答案、证据来源（文献/说明书/内部资料）、版本与审核记录；
  • 动态维护：新数据发布、说明书更新、高频新问题→及时增补（月度评审）。

7.3 应答质量与时限

  • 准确性：只引用经批准来源；不确定不猜测，标注"待内部核实"；
  • 时限：紧急咨询（如疑似严重ADR线索）立即升级处理；常规咨询24-48小时内应答（以公司SLA为准）；
  • 记录：全流程留痕，可追溯。

7.4 超适应症（Off-label）问题处理（合规重点）

  • 医生主动询问超适应症信息：可提供科学文献（如发表的研究数据），但不得主动建议/鼓励超适应症用药，需提示以说明书与临床判断为准；
  • 患者咨询：转介医生，医学部不提供个体化治疗建议；
  • 红线：任何销售/市场行为不得利用超适应症信息推广产品。

第10章 合规与药物警戒

10.1 推广材料医学审核

审核要素： - 医学准确性（数据、机制、安全性表述与证据一致）； - 适应症合规（仅获批适应症；超适应症信息仅限医生主动询问时的科学沟通）； - 引文规范（来源可查、版本最新）； - 无绝对化/夸张表述、无误导性对比； - 利益冲突与商标/版权合规。

流程：材料提交→医学初审→合规复核→批准/退回修改→版本登记与分发→到期复审。

10.2 会议/活动合规检查点

  • 场地与餐饮标准符合政策（不得奢华）；
  • 参会人员资质与地域合规（不得向非目标人群支付差旅/劳务）；
  • 讲者劳务费市场公允、协议齐备；
  • 会议内容不得有推广未获批适应症、贬低竞品等行为；
  • 抽奖/礼品符合规定（一般不向HCP赠送高价值礼品）。

10.3 药物警戒（PV）与医学部接口（重中之重）

  • 医学经理是PV线索的重要入口之一：接到任何"疑似不良反应（ADR/ICSR）"线索（来自会议、拜访、MI、内部同事、患者），第一时间按公司SOP转交PV团队，不延迟、不隐瞒；
  • 个体报告（ICSR）基本要素：可识别的患者、可识别的报告者、怀疑药品（BL-B01D1）、不良反应事件——四要素缺失也需上报（按SOP补充随访）；
  • 上报时限：严重不良反应按法规（通常24小时-7天）执行，以公司PV SOP为准；
  • 信号与风险管理（了解层面）：PV团队负责信号检测、RMP（风险管理计划）、PSUR/DSUR撰写；医学部提供医学解读支持；
  • 医学部提示义务：在对外学术沟通中，如遇安全性问题，正确引导至说明书/PV流程，不自行"解释"不良反应发生率之外的安全问题。

10.4 费用与行为合规

  • 咨询/讲者/研究费用遵循公司政策与市场公允价；
  • 费用记录真实、凭证完整、用途可解释；
  • 不得以任何形式换取处方、进院或其他商业利益。

第13章 高频业务场景演练（15例）

每题先自行思考，再对照"处理要点"。重点训练"合规边界+医学准确+推动落地"三位一体的处理习惯。

场景1：科室会上，医生问"BL-B01D1在HER2 IHC 0的TNBC患者里疗效怎么样？"（此时TNBC适应症若未获批） 处理要点：区分"获批信息"与"研究信息"。TNBC尚未获批时，不主动推广；医生主动询问时，可基于已发表研究数据（PANKU-Breast 02，ASCO 2026）客观陈述"III期研究中HER2 IHC 0亚组mPFS 8.3个月 vs 化疗2.6个月"，同时提示：该适应症尚在审评中，最终以获批说明书记载为准，临床决策请结合患者情况由医生判断。

场景2：销售转来一条信息"有位医生反映患者用后出现发热" 处理要点：凡涉及疑似不良反应，一律先走PV流程——第一时间通知PV接口人，按四要素记录（患者、报告者、怀疑药品、事件详情），不自行判断"与药物无关"。医学部可事后协助安全性数据解读。

场景3：一位乳腺外科大主任提出想做一项"BL-B01D1在HER2低表达晚期乳腺癌的真实世界研究" 处理要点：欢迎并引导至IIR流程——请研究者提交研究方案与科学依据；医学部评估证据缺口契合度、方案科学性、可行性；合规审查（COI、预算、数据归属）；按公司IIR SOP推进。同时评估是否与公司医学计划优先级一致（如一致，优先支持）。

场景4：医生拿T-DXd数据质疑"为什么用你们的药？" 处理要点：不贬低竞品，谈差异化：① 机制层面——EGFR×HER3双靶覆盖HER2 IHC 0与低表达，不依赖HER2表达水平；② 证据层面——≥2L TNBC全人群III期双阳性（mPFS 8.5个月/OS 15.9个月/HR 0.29/0.60），HER2低表达亚组mPFS 9.7个月（非头对头，谨慎表述）；③ 安全层面——ILD 1.4%且无≥3级，无腹泻/口腔炎，以血液学毒性为主。强调"联合/序贯/个体化选择"由临床判断。

场景5：会议邀请某大咖讲者，对方提出劳务费明显高于公司标准 处理要点：礼貌坚持公司政策与市场公允价标准，可协商服务内容（时长、场次、课件开发）而非直接涨费；超标准需按审批流程特批，严禁个人承诺；坚持COI声明。

场景6：患者家属来电咨询"这个药对我家人有效吗？" 处理要点：不提供个体化治疗建议——礼貌说明医学部不提供个体化诊疗意见，建议与主治医生沟通；可提供经批准的患者教育资料（疾病科普）；如涉及用药安全/不良反应线索，转PV流程。

场景7：市场部要求医学部在卫星会上安排"与T-DXd头对头"的讲题 处理要点：沟通调整讲题方向——避免直接贬低竞品的头对头叙事，改为"ADC类药物治疗演进与双抗ADC差异化机制"等合规、科学的讲题；数据对比须客观、标注非头对头、注明来源。

场景8：KOL提出想参与公司的咨询委员会（Advisory Board） 处理要点：按公司AB管理流程——确认咨询议题（如TNBC证据策略、指南推广路径）、审查COI、签署协议与劳务标准、会议记录归档、产出洞见用于医学策略。

场景9：销售经理要求医学部"尽快出一个能压过竞品的数据" 处理要点：坚持科学底线——医学部只提供真实、经批准的证据；引导以科学沟通方式呈现差异化（机制、人群覆盖、安全性），而非选择性引用或攻击性表述；解释监管风险。

场景10：公司获批新适应症（如ESCC）当天，销售要"一页纸卖点" 处理要点：快速产出经医学审核的新适应症培训卡（获批信息：人群、数据mPFS 4.17/OS 9.79/ORR 35.3%、安全性要点、合规提示"仅限获批人群"）；安排培训与Q&A。

场景11：媒体致电询问BL-B01D1在研数据（如1L TNBC研究） 处理要点：未经授权的医学部人员不对外评论；记录媒体诉求，转交公司公关/对外沟通授权人；如参与口径制定，确保信息准确、不夸大、无未获批声明。

场景12：内部邮件中同事误把"TNBC NDA受理"写成"已获批" 处理要点：及时纠正——NDA受理≠批准；明确当前状态（受理、在审），避免对外传播错误信息造成合规风险；顺手更新内部FAQ。

场景13：医生询问"BL-B01D1与化疗序贯还是联合更好？" 处理要点：如实说明——目前无充分序贯/联合证据；基于获批适应症数据回答单药疗效；指出联合治疗探索方向（如与免疫联合）正处于研究阶段，最终以指南与临床判断为准。

场景14：MI趋势显示医生高频咨询"血液学毒性如何处理" 处理要点：识别为医学教育需求——开发"ADC血液学毒性管理"医学教育内容（监测频率、剂量调整、G-CSF支持、发热性中性粒细胞减少处理），纳入卫星会/科室会主题，同时更新医学问答库。

场景15：上级要求你在一周内准备一份"BL-B01D1乳腺癌医学年度计划"初稿 处理要点：按12.7模板组织：先与MSL/市场对齐洞察，输出医学目标（证据生成+沟通+教育），列出优先级项目（RWS启动、IIR支持、指南纳入行动、卫星会系列），给出预算与KPI框架；标注待确认项。

第14章 上岗自测与30-60-90天计划
