一、上市后潜在课题方向（结合乳腺癌研究前景）

前景判断：乳腺癌已进入"ADC 主导的精准治疗时代"——TROP2/HER2 ADC 后线确立、ADC 前移至一线（ASCENT-03/04、TROPION-Breast02）、双抗ADC 开启新范式（BL-B01D1 为首个获批）；未满足需求集中在 HER2 IHC 0 人群、序贯/联合策略、生物标志物驱动人群选择、前线推进、生活质量与经济学证据。以下课题按 7 大方向展开。

方向 A · 疗效与人群扩展（RWS / IIR 首选）

#课题（示例题目）类型目标人群设计要点 / 主要终点科学意义优先级
A1BL-B01D1 在 HER2 IHC 0 晚期 TNBC 中的真实世界疗效与安全性（前瞻多中心登记）前瞻 RWS/登记≥2L TNBC，IHC 0（约占50%）rwPFS/TTNT/RWOS；BIRC 裁定；索引日规则防不朽偏倚差异化阵地，填补 IHC 0 真实世界证据（III期亚组 mPFS 8.3 月）高
A2ADC 序贯策略研究：BL-B01D1→T-DXd/SG 及反向序贯的真实世界疗效回顾性 RWS经治 mTNBC/HER2 低表达TTNT、后线 PFS、交叉分析（RPSFT）回答临床"先用什么、后用什么"；共享 TOP1 载荷的交叉耐药问题高
A3HER2 低表达 vs IHC 0 晚期 TNBC 的疗效差异分析（合并 PANKU-Breast 02 数据+真实世界）数据合并/回顾TNBC 全人群亚组比较、交互检验验证"不依赖 HER2 表达"的机制叙事中
A4肝转移/内脏转移人群专向研究（PANKU-Breast 02 肝转移 mPFS 9.9 月信号）前瞻/回顾伴内脏转移 mTNBCPFS、OS、缓解深度难治人群证据，支持"进展快者获益"中
A5初诊非 TNBC 转化为 TNBC 表型人群获益分析（亚组 mPFS 11.3 月）回顾/前瞻组织学转化人群rwPFS、生物标志物（HR 动态）探索"跨表型"获益机制中
A6既往免疫经治患者的再治疗/序贯研究（约23%入组仍获益）回顾 RWSPD-(L)1 经治 mTNBCrwPFS、TTNT、安全性"免疫后 ADC"真实世界路径中

方向 B · 联合治疗（需前瞻/研究者发起研究，谨慎立项）

#课题类型目标人群设计要点意义优先级
B1BL-B01D1 + PD-1/PD-L1 抑制剂（参考 ASCENT-04 模式）IIR/公司研究1L/≥2L TNBC剂量爬坡+扩展；ORR/PFS；安全性（血液学叠加）双抗ADC+IO 协同（化疗样免疫原性死亡+微环境重塑）高（长期）
B2BL-B01D1 + 抗血管生成（贝伐珠单抗类）IIR经治 mTNBC单臂 ORR/安全性改善递送与微环境中
B3BL-B01D1 + CDK4/6i（HR+/HER2- 后线）IIR内分泌耐药 HR+/HER2-Simon 两阶段 ORRADC+细胞周期抑制协同低-中
B4BL-B01D1 + PARP 抑制剂（gBRCA mTNBC）IIRgBRCA 突变单臂 ORR/PFS；双 DNA 损伤叠加安全性精准联合方向低

方向 C · 前线推进（战略级，与注册联动）

#课题类型要点优先级
C11L 晚期 TNBC（不适合免疫）——IZABRIGHT-Breast01 全球 III期中国亚组分析与数据支持公司研究/亚组全球 560 例、BICR PFS 主终点、2028 读出；中国亚组差异分析高（战略）
C2新辅助/辅助探索（早期 TNBC；参考 KEYNOTE-522 模式）公司/IIRpCR 主终点（新辅助）；需免疫/化疗联合设计中（远期）
C3ER 低表达 HR+/HER2- 人群（不适合内分泌，约10%）公司研究1L 人群纳入 IZABRIGHT-Breast01；中国数据支持中

方向 D · 生物标志物与转化（差异化壁垒）

#课题类型要点优先级
D1HER3/EGFR 表达作为疗效预测标志物（SCLC 队列：HER3 阳性 ORR 68.8% vs 14.3%）转化/伴随前瞻采集、IHC cut-off 标准化、多中心验证高
D2ctDNA/MRD 动态监测（参考刘强团队早期 TNBC 模型）转化（IIR 附加）治疗响应/耐药早期信号中
D3耐药机制研究（进展后活检：靶点丢失/载荷外排/旁路激活）转化多组学；为下一代双抗ADC 提供依据中
D4EGFR-HER3 异源二聚化/双靶共表达与疗效关联转化机制性探索低

方向 E · 安全性管理（患者体验与依从性）

#课题类型要点优先级
E1血液学毒性规范化管理路径研究（G-CSF 策略/FN 预防/剂量调整）RWS/教育整合指南+真实实践；产出管理手册高
E2ILD 长期安全性监测（发生率低但需随访；说明书 1.0%）前瞻安全登记风险因素、影像监测规范中
E3特殊人群（老年/肝肾功能不全）PK 与安全数据补充IIR/PK 子研究说明书未覆盖人群中

方向 F · 生活质量与经济学（准入/医保证据）

#课题类型要点优先级
F1PRO/生活质量研究（对比化疗：无腹泻口腔炎 vs 血液学）RWS/PRO 子研究EORTC QLQ-C30/BR23；治疗体验中
F2药物经济学/成本-效果（≥2L TNBC 场景）药物经济学QALY/ICER，支撑医保/HTA中

方向 G · 特殊场景与规范教育

#课题要点优先级
G1乳腺癌脑转移探索（ADC 旁观者效应）小样本探索（原发脑转移人群）低
G2真实世界治疗模式研究（剂量/周期/联合实践）描述性 RWS，为指南落地提供数据中
G3HER2 IHC 判读规范化教育（低表达/IHC 0 检测一致性）检测一致性研究+教育项目中
